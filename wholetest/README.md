# wholetest —— 整机测试规格

本目录是 EtherCAT 主站**整机测试**的主控文档集。它规定主站在服役条件下必须通过的考验、
为证明通过所必须采集的记录，以及把记录映射为结论的判定规则。

**本目录描述"必须经受什么"，不描述"曾经发生过什么"。** 历史问题登记在
`docs/requirements/layering-plan.md`，与本目录相互独立：本目录不以它为输入，它也不以
本目录为输入。实现变更不改变本目录的场景集合，只改变"是否通过"。

## 文件

| 文件 | 作用 | 权威性 |
| --- | --- | --- |

## 怎么用

**要加一个测试场景**：先在 `test-plan.md` 第 7 章按 `WT-<边界>-<序号>` 分配编号并写明
判定准则与所需记录项，再同步 `scenarios.tsv`。编号一经分配不得回收。

**要实现一个采集点**：查 `records.tsv`，按其中的"缺失时表示"决定取不到时写什么。
`na` 与 `unknown` 都不得以零值代替。

**要写一个判定工具**：只读记录与被测物契约，不读开发史、不读提交记录、不假设历史故障形态。
输出三值结论（通过／不通过／无法判定）。阈值必须已在主文档中获批，否则只输出原始量。
