# Orange Pi EtherCAT 双轴电机系统说明

## 硬件配置

### 驱动器与电机
- **型号**: CyberBeast ISVD90RC-300B-100-70
- **协议**: CiA 402 (CANopen over EtherCAT)
- **从站数量**: 2 轴
- **从站位置**: 轴1=从站0, 轴2=从站1

### 编码器参数
- **分辨率**: **16384 脉冲/转** (14-bit编码器)
  - 对象: 0x608F:01
  - 这是**电机转子**侧编码器，不是负载侧
- **齿轮比**: **28:1**
  - 对象: 0x6091
  - 电机轴转28圈，负载侧转1圈
- **负载侧分辨率**: **16384 × 28 = 458,752 脉冲/转**

### 力矩参数
- **额定力矩**: 从 0x6076:00 读取（单位：mNm，毫牛米）
- **显示单位**: ‰（千分之额定力矩）

## 当前系统行为

### 零点定义
- **当前零点**: 上电时的编码器位置
- **初始位置**: 从启动日志读取，例如 `[0]=49830 [1]=500272`
- **坐标系**: 相对位置，无绝对零点
- **累积特性**: 位置值可以超过 ±2^31，支持多圈累积

### 位置单位转换

| 单位 | 公式 | 示例（60000 脉冲） |
|------|------|-------------------|
| **脉冲** | 原始值 | 60000 |
| **电机转数** | 脉冲 ÷ 16384 | 3.66 转 |
| **负载转数** | 脉冲 ÷ (16384×28) | 0.131 转 |
| **负载角度** | (脉冲 ÷ (16384×28)) × 360° | 47.1° |

### 速度单位转换

| 单位 | 公式 |
|------|------|
| **脉冲/秒** | 原始 PDO 值 |
| **电机 RPM** | (脉冲/秒 ÷ 16384) × 60 |
| **负载 RPM** | (脉冲/秒 ÷ (16384×28)) × 60 |

## 当前工具说明

### emaster-watch（监控工具）
```bash
sudo ~/ethercat-master/build/bench/tools/emaster_watch/emaster-watch
```
**显示内容**：
- 实际位置：**脉冲**（编码器累积计数）
- 速度：**脉冲/秒**
- PDO目标/计划目标：**脉冲**
- 跟随误差：**脉冲**（实际位置 - PDO目标）
- 力矩：**‰额定**（千分之额定力矩）

### emaster-move（控制工具）
```bash
sudo ~/ethercat-master/build/bench/tools/emaster_move/emaster-move
```
**输入格式**：
```
位置> 60000 510000    # 单位：脉冲
```

## 限制与保护

### 当前状态
- **软件限位**: ❌ 未实现
- **速度限制**: ❌ 未实现
- **加速度限制**: ❌ 未实现
- **急停保护**: ⚠️ 仅 Ctrl+C 停止主站

### 驱动器本身支持
- **硬件限位开关**: 需查阅驱动器手册 0x6065 (Following error window)
- **跟随误差保护**: 驱动器内部监控，超限触发 Quick Stop
- **过流保护**: 驱动器硬件保护
- **过压/欠压保护**: 驱动器硬件保护

### 建议添加的软件限制
1. **软件限位**：限制位置范围，防止机械干涉
2. **速度限制**：限制最大速度（当前 target_velocity 在 RxPDO 中，但主站未使用）
3. **平滑加减速**：梯形/S型速度曲线，避免冲击
4. **跟随误差监控**：软件层二次检查，超限则主动停止
