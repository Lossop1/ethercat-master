# EtherCAT 主站功能要求

根据最终目标（机器人控制使用的功能完善主站）系统梳理的功能清单，按优先级和层次组织。

---

## P0：基础通信与控制（必须完成）

这些是主站能工作的最低要求，缺一不可。

### 通信基础
- [x] 设备发现和拓扑验证
- [x] PDO 映射配置
- [x] 周期通信（DC 同步）
- [x] WKC 验证

### 基本控制
- [x] CiA 402 状态机（到 OPERATIONAL ENABLED）
- [x] CSP 模式（周期同步位置控制）
- [x] 位置目标接口（position_target_source）
- [x] 位置反馈读取

### 基本安全
- [x] 软限位检查
- [x] 跟随误差检查
- [x] 故障锁存
- [x] 安全停机（失能、恢复 INIT）

---

## P1：核心监控与保护（功能完善的前提）

没有这些，主站无法安全地用于实际机器人控制。

### 必要的监控
- [x] **电流监控**（6078h）- P4.3 完成：SDO 观测线程约 50ms 周期读取，填入报告字段
- [x] **母线电压监控**（6079h）- P4.3 完成，同上
- [x] **温度监控**（200Bh:01h MOSFET / 200Bh:02h 电机）- P4.3 完成，同上
- [x] 位置、速度、力矩反馈（已有）
- [x] 跟随误差监控（已有）

注：以上三个量因 ESI 将对应模块声明为 `Fixed="true"` 且 `supports_pdo_configuration=false`，
无法映射进 TxPDO，走 SDO 慢速通道（约 3ms 往返）。观测线程在周期外读取，
周期线程只做加锁拷贝，不阻塞实时路径。

### 异常检测
- [ ] **碰撞检测**（电流突变）
- [ ] **卡死检测**（目标在变但位置不动）
- [ ] **过载检测**（持续高电流）
- [ ] **过热检测**（温度超限）
- [ ] **欠压/过压检测**
- [ ] **编码器故障检测**
- [x] WKC 错误检测（已有）
- [x] 周期 deadline 检测（已有）

### 持续运行能力
- [x] **持续运动验证**（连续数小时接收位置指令）- P1.6 完成，300s CSP 双轴保持位置，wkc_error=0
- [x] **实时性保证**（持续高频命令下的周期稳定性）- P1.4 完成，15 分钟 idle，deadline_missed=0
- [ ] **命令队列管理**（队列满时的策略）

---

## P2：多模式控制（扩展控制能力）

机器人可能需要不同的控制模式，但 CSP 是基础。

- [ ] **CSV 模式**（周期同步速度控制）- 代码有接口，ESI 与手册冲突未验证（P5.3 硬件阻塞）
- [ ] **CST 模式**（周期同步力矩控制）- 代码有接口，未真机验证
- [ ] **混合控制模式**（不同轴不同模式）
- [ ] **运行时模式切换**（不重启切换控制模式）

---

## P3：故障处理与恢复（生产环境必需）

基础功能可以检测故障，但需要更完善的处理机制。

### 分级停机
- [x] 正常停止（已有，轨迹完成后停止）
- [ ] **快速停止**（立即减速停止）
- [ ] **急停**（最快速度停止，可能不遵守加速度限制）

### 故障恢复
- [ ] **故障日志**（时间、轴、故障类型、上下文）
- [ ] **故障清除流程**
- [ ] **自动重试机制**（某些临时故障）
- [ ] **降级运行**（部分轴故障，其他轴继续）

## 当前状态总结

- **P0（基础）**：完成，CSP 模式可用
- **P1（核心）**：持续运行已验证（P1.4/P1.6 完成）；电流/电压/温度监控已实现（P4.3 SDO 观测线程）；
  异常检测判据（碰撞、卡死、过载、过热、欠压/过压、编码器故障）尚未实现
- **P2（多模式）**：CSV/CST 代码接口存在但未真机验证（P5.3 硬件阻塞）
- **P3（故障恢复）**：Fault Reset 调用路径存在但未长时验证（P2.5 硬件阻塞）
- **P4（诊断）**：运行报告和命令服务器已实现，协议规格见 `docs/protocol/command-protocol-v1.md`
- **P5-P6**：基本未实现

**下一步重点**：P1 监控能力（电流/电压/温度 SDO 轮询）或直接对接工程应用（P6 已完成，协议文档和安全约束齐备）。

## 已知代码缺陷

以下是当前代码中已识别但尚未修复的问题，按影响分类。

### 功能未实现

（暂无。此前的 P4.3 SDO 慢速通道条目已移除——该功能已于 2026-09-12 实现并有实机日志佐证。）

### 硬件阻塞

**P2.5 - Fault Reset 未真机验证**
- 影响：CiA402 状态机 `Fault → Fault Reset → Switch On Disabled` 路径未完整验证
- 原因：驱动器静置后位置反馈正常但不执行 607A，断电重启恢复（设备参数问题）
- 状态：调用路径已存在，触发测试需先解决硬件问题
- 追踪：layering-plan.md P2.5，memory/drive-idle-no-response.md

**P5.3 - CSV 模式 ESI 与手册冲突**
- 影响：`fixed_csv` 的 1A02 PDO 内容 ESI 与驱动器手册不一致
- 状态：需真机读回确认，当前 CSP 专项不要求
- 追踪：layering-plan.md P5.3
