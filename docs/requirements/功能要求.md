# EtherCAT 主站功能要求

根据最终目标（机器人控制使用的功能完善主站）系统梳理的功能清单，按优先级和层次组织。

---

## P0：基础通信与控制（必须完成）

这些是主站能工作的最低要求，缺一不可。

### 通信基础
- [x] 设备发现和拓扑验证
- [x] PDO 映射配置
- [x] 周期通信（DC 同步）
- [x] WKC 验证

### 基本控制
- [x] CiA 402 状态机（到 OPERATIONAL ENABLED）
- [x] CSP 模式（周期同步位置控制）
- [x] 位置目标接口（position_target_source）
- [x] 位置反馈读取

### 基本安全
- [x] 软限位检查
- [x] 跟随误差检查
- [x] 故障锁存
- [x] 安全停机（失能、恢复 INIT）

---

## P1：核心监控与保护（功能完善的前提）

没有这些，主站无法安全地用于实际机器人控制。

### 必要的监控
- [ ] **电流监控**（6078h）- 碰撞检测、过载检测的基础
- [ ] **母线电压监控**（6079h）- 欠压/过压保护
- [ ] **温度监控**（电机、驱动器）- 过热保护
- [x] 位置、速度、力矩反馈（已有）
- [x] 跟随误差监控（已有）

### 异常检测
- [ ] **碰撞检测**（电流突变）
- [ ] **卡死检测**（目标在变但位置不动）
- [ ] **过载检测**（持续高电流）
- [ ] **过热检测**（温度超限）
- [ ] **欠压/过压检测**
- [ ] **编码器故障检测**
- [x] WKC 错误检测（已有）
- [x] 周期 deadline 检测（已有）

### 持续运行能力
- [ ] **持续运动验证**（连续数小时接收位置指令）
- [ ] **实时性保证**（持续高频命令下的周期稳定性）
- [ ] **命令队列管理**（队列满时的策略）

---

## P2：多模式控制（扩展控制能力）

机器人可能需要不同的控制模式，但 CSP 是基础。

- [ ] **CSV 模式**（周期同步速度控制）- 代码有接口但未验证
- [ ] **CST 模式**（周期同步力矩控制）
- [ ] **混合控制模式**（不同轴不同模式）
- [ ] **运行时模式切换**（不重启切换控制模式）

---

## P3：故障处理与恢复（生产环境必需）

基础功能可以检测故障，但需要更完善的处理机制。

### 分级停机
- [x] 正常停止（已有，轨迹完成后停止）
- [ ] **快速停止**（立即减速停止）
- [ ] **急停**（最快速度停止，可能不遵守加速度限制）

### 故障恢复
- [ ] **故障日志**（时间、轴、故障类型、上下文）
- [ ] **故障清除流程**
- [ ] **自动重试机制**（某些临时故障）
- [ ] **降级运行**（部分轴故障，其他轴继续）

---

## P4：诊断与调试（开发和维护）

帮助开发者和用户理解系统行为。

### 运行时诊断
- [x] 运行报告（JSON，已有）
- [ ] **实时状态查询接口**（当前已通过命令服务器部分实现）
- [ ] **周期时序统计详细信息**（抖动分布、最大/最小/平均）
- [ ] **通信质量统计**（丢包率、错误率趋势）

### 调试工具
- [ ] **实时数据流**（用于示波器、图形化调试）
- [ ] **历史数据记录**（长期趋势分析）
- [ ] **性能分析工具**（识别瓶颈）

---

## P5：配置与扩展（灵活性）

提高系统的适应性和易用性。

### 配置灵活性
- [ ] **运行时配置调整**（改变控制参数而不重启）
- [ ] **周期时间可调**（1ms, 2ms, 4ms 等）
- [x] 多机器人配置管理（已通过部署配置实现）

### 扩展能力
- [ ] **轴数动态**（当前固定在配置中，扩展为支持运行时变化）
- [ ] **热插拔**（运行时添加/移除从站）- 工业场景罕见，优先级低
- [ ] **多主站协同**（分布式控制）- 高级场景，优先级低

---

## P6：性能优化（锦上添花）

基础功能工作后的性能提升。

- [ ] **零拷贝优化**（减少数据复制）
- [ ] **多核利用**（如果瓶颈在 CPU）
- [ ] **优先级调度**（不同轴的优先级）
- [ ] **内存池管理**（减少动态分配）

---

## 当前状态总结

- **P0（基础）**：大部分完成，CSP 模式基本可用
- **P1（核心）**：电流/电压/温度监控缺失，持续运行未验证
- **P2-P6**：基本未实现

**下一步重点**：完成 P1 的监控和持续运行验证，这是"功能完善"的门槛。
